# 死域净化玩法测试文档

## 一、测试思路

我会按 **流程、状态、交互、边界、联机、异常** 这几个方向来设计测试。

死域净化的核心流程一般是：

1. 玩家进入死域范围
2. 角色受到死域影响
3. 破坏枝节或污染源
4. 击败关键敌人
5. 完成净化
6. 场景恢复并发放奖励

所以测试重点是：

1. 流程能不能正常走通
2. 负面状态是否正确生效和解除
3. 枝节、敌人、奖励是否正确刷新和结算
4. 中断后能不能恢复
5. 联机下是否会不同步

---

## 二、测试点拆解

### 1. 区域触发

- 进入死域后是否正确触发玩法
- 边界判定是否准确
- 反复进出边界是否会异常重复触发
- 已完成的死域是否不会重复开启

### 2. 负面状态

- 进入后是否施加负面效果
- 负面值是否持续累积
- 切换角色后状态是否正确
- 净化后状态是否清除
- 死亡、复活后状态是否正常

### 3. 枝节/污染源交互

- 是否能正确识别和攻击枝节
- 正确交互方式是否能推进流程
- 错误交互方式是否不会误推进
- 多个枝节的计数是否正确
- 已破坏目标是否不会重复统计

### 4. 战斗流程

- 关键敌人是否按条件刷新
- 刷新位置、数量、类型是否正确
- 击败敌人后流程是否继续推进
- 敌人脱战、卡地形时是否会卡死

### 5. 净化完成

- 净化条件是否判断正确
- 场景污染效果是否消失
- 奖励是否正确生成或发放
- 完成后是否不会重复领奖

### 6. UI 与表现

- 区域提示是否正确
- 目标提示是否清晰
- 净化前后特效、音效是否明显
- 完成提示是否正常出现

### 7. 联机与异常

- 多人联机下进度是否同步
- 枝节破坏和敌人击败是否同步
- 中途退出、传送、下线后是否能恢复
- 是否会出现重复发奖或流程卡死

---

## 三、核心测试用例

### 1. 基础流程

1. 玩家进入死域，验证玩法触发、负面状态生效、UI 提示出现。
2. 正常完成一次死域净化，验证枝节破坏、敌人击败、净化完成、奖励发放全流程正确。
3. 净化完成后再次进入，验证不会重复触发、不会重复刷怪、不会重复领奖。

### 2. 负面状态

1. 玩家在死域内停留一段时间，验证负面状态持续累积。
2. 完成净化后，验证负面状态停止并按设计清除。
3. 死域内死亡并复活后，验证玩法不会卡死，状态恢复正确。

### 3. 枝节交互

1. 单个枝节可被正常破坏，并推进流程。
2. 多个枝节全部破坏后，验证计数准确并进入下一阶段。
3. 使用错误方式交互时，验证不会错误推进流程。

### 4. 战斗阶段

1. 满足条件后关键敌人正常刷新。
2. 击败全部关键敌人后，验证流程进入净化完成阶段。
3. 将敌人拉远、脱战或卡地形，验证不会导致流程永久卡死。

### 5. 中断恢复

1. 净化过程中传送离开再回来，验证进度恢复符合设计。
2. 净化过程中下线重登，验证状态保存正确。
3. 净化过程中角色死亡后继续，验证流程可继续或按设计重置。

### 6. 联机

1. 多名玩家共同推进净化，验证进度同步。
2. 联机中有人退出，验证剩余玩家流程不中断。
3. 房主和客机完成后，验证奖励和完成状态一致。

---

## 四、边界测试

1. 玩家在死域边缘反复进出，验证不会异常反复触发。
2. 最后一个枝节被破坏时，验证完成判定是否准确。
3. 最后一只关键敌人死亡瞬间，验证不会重复结算。
4. 净化完成瞬间切人、冲刺、攀爬、受击，验证状态切换稳定。
5. 弱网环境下验证枝节、敌人、奖励状态最终可同步。

---

## 五、风险点

1. 边界判定不准导致反复触发。
2. 枝节计数不同步导致无法完成。
3. 敌人卡地形或脱战导致流程卡死。
4. 联机下奖励重复发放或漏发。
5. 玩家传送、下线后状态恢复异常。
6. 净化完成后污染表现没有完全清理。

---

## 六、总结

如果作为笔试题，我会重点覆盖：

1. 基础流程
2. 状态变化
3. 关键交互
4. 边界情况
5. 联机与异常恢复

这样写比较像测试设计题的答法，也能体现自己有完整的测试思路。
